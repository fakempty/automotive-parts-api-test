# Лабораторна робота №8 — Звіт про виявлення та усунення Flaky Tests

| № | Проблема | Симптом | Root Cause | Виправлення |
|---|---|---|---|---|
| 1 | **Order dependency** | Тест падає при ізольованому запуску або зміні порядку | Залежність від запису, створеного іншим тестом | Створення потрібних тестових даних у самому тесті |
| 2 | **Shared state / dirty data** | Конфлікти або залишкові записи при повторних запусках | Фіксовані ключі без очищення після тесту | Унікальні значення (`UUID`) та очищення в `@AfterEach` |
| 3 | **Fixed wait / timing dependency** | Періодичні падіння при затримках відповіді | Фіксована пауза (`Thread.sleep`) замість перевірки умови | Очікування умови (`awaitCondition`) з таймаутом |
| 4 | **Недетермінований порядок / стан** | Нестабільний результат залежно від порядку/стану | Несортовані дані та відсутність ізоляції вибірки | Фільтрація своїх даних та явне сортування |
